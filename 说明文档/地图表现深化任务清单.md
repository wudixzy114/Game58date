# 地图表现深化任务清单

## 目标

本清单用于跟踪地图表现深化相关开发，覆盖三个主方向：

1. 地表深化
2. 环境实体深化
3. 天气与粒子深化

后续每完成一项，直接在此文件中勾选并补充必要备注，防止阶段性目标遗忘。

## 一、地表深化

### 1. 地貌扩展

- [x] 在现有 `Shore / Plains / Hills / Mountains` 基础上扩展湿地 `Wetland`
- [x] 扩展林地 `Woodland`
- [x] 扩展高寒带 `Alpine`
- [x] 扩展碎石坡 `Scree`
- [x] 重新梳理 `BiomeKind` 与 `WorldSample`，为新增地貌保留足够字段
- [x] 调整 `WorldFieldSampler` 的温度、湿度、坡度、海拔判定规则，使新增地貌具备稳定生成条件
- [x] 为新增地貌设计与现有 biome 的平滑过渡规则，避免硬切

### 2. 地表材质分层

- [x] 为湿地增加泥地、浅水、苔藓、湿草等表层语义
- [x] 为林地增加腐殖土、落叶层、树根裸露地表等表层语义

- [x] 为碎石坡增加砾石、裸岩、稀疏土层等表层语义
- [x] 扩展 `SurfaceMaterialKind`
- [x] 扩展 `SurfaceMaterialResolver`
- [x] 扩展 `TerrainFaceTextureResolver`

### 3. 材质与颜色细化

- [x] 为不同地貌补充更细的程序化纹理 tile
- [ ] 增加同类材质内部的明度、色温、粗糙度变化
- [x] 让湿地地表整体更冷、更湿、更暗
- [x] 让林地地表整体更厚重、更有腐殖感
- [x] 让高寒带地表整体更稀薄、更高反差

### 4. 地表表现联动

- [x] 让坡度参与表面材质分层，而不只决定 cliff
